# 免训练：Ollama 记忆增强法 (Few-Shot)

## 什么是记忆增强法？

这是一种**不需要微调训练**（In-Context Learning）就能让模型获得特定性格和记忆的方法。

它的原理非常简单：直接把数据集里最精彩的几段对话，写入到模型的“永久记忆区”（Modelfile）中。每次你和模型聊天时，它都会先“回想”起这些示例，然后模仿这种语气和你对话。

### 为什么推荐这个方法？
- **零成本**：不需要 GPU，不需要漫长的训练等待。
- **不降智**：它使用的是原版模型的“大脑”，逻辑能力 100% 保留，不会出现微调过度导致的“答非所问”。
- **即时生效**：脚本运行只需要 1 秒。

---

## 如何使用

我们提供了一个自动化脚本，可以从你的训练数据集中提取精华，自动生成 Modelfile。

### 1. 准备工作
确保你已经下载了基础底座模型（建议使用 Qwen2.5-1.5B，聪明且轻量）：
```bash
ollama pull qwen2.5:1.5b
```

### 2. 生成 Modelfile
运行以下命令，指定你的数据集路径和角色名称：

```bash
# 用法：python3 create_fewshot_modelfile.py [数据集路径]
cd /Users/admin/Documents/ollama_web/finetune
python3 create_fewshot_modelfile.py datasets/linzhi/train.jsonl
```

脚本会自动：
1. 读取 `datasets/linzhi/train.jsonl`。
2. 挑选出包含 "xinzhi" 或 "林栀" 的高质量对话。
3. 生成一个名为 `Modelfile.linzhi_fewshot` 的文件。

### 3. 创建并运行模型
使用生成的 Modelfile 创建一个新的 Ollama 模型：

```bash
# 1. 创建模型
ollama create linzhi-fast -f Modelfile.linzhi_fewshot

# 2. 开始聊天
ollama run linzhi-fast
```

## 常见问题

**Q: 我可以用这个方法做其他角色吗？**
A: 可以！只需要把数据集换成其他角色的 JSONL 文件即可。

**Q: 为什么模型有时候还是会跳戏？**
A: 因为这只是“模仿”。如果想要更深层的稳定性，可以尝试结合使用：先用这个方法测试数据质量，满意后再进行 LoRA 微调（使用我们推荐的 `Rank=4` 黄金配置）。
