# 快速开始 - 5分钟上手

## 🚀 一键启动菜单

```bash
cd finetune
./train --menu
```

## 🎯 常用流程

### 创建新角色 → 训练 → 导入

```bash
# 1. 启动菜单
./train --menu

# 2. 创建角色
选择: 6) 角色管理 → 1) 创建新角色
按提示输入角色信息

# 3. 补充数据
编辑: datasets/{角色ID}/train.jsonl
目标: 至少 200 条，推荐 1000+ 条

# 4. 开始训练
选择: 1) 角色训练 → 1) 交互式选择角色
选择新创建的角色

# 5. 导入到 Ollama
选择: 4) Ollama模型管理 → 2) 导入模型

# 6. 测试效果
选择: 5) 模型测试
或在 Web UI 中测试
```

### 删除不需要的角色

```bash
./train --menu
选择: 6) 角色管理 → 4) 删除角色
选择要删除的角色编号
输入 yes 确认
```

## 🎨 角色管理功能 🆕

### 1) 🆕 创建新角色
- 交互式输入角色信息
- 自动生成数据集模板
- 可选 AI 辅助生成初始数据
- 自动更新配置文件

### 2) 📋 查看所有角色
- 列出所有已创建的角色
- 显示名字和描述

### 3) 🔍 查看角色详情
- 基本信息（ID、名字、描述）
- 数据集状态（条数）
- 训练输出（大小）
- 训练参数配置

### 4) 🗑️ 删除角色
- 一键删除所有相关文件
- 包括：数据集、训练输出、配置
- 需要确认，防止误删

## 💡 快速提示

### 数据量建议
- 测试: 20-50 条（快速验证）
- 最小可用: 200-300 条
- 推荐: 1000+ 条
- 优秀: 2000+ 条

### 训练时间估算
- 50 条数据，3 轮: 约 5 分钟
- 500 条数据，4 轮: 约 40 分钟
- 1000 条数据，4 轮: 约 80 分钟

### 常见问题

**Q: 创建角色后在哪里？**
A: `datasets/{角色ID}/` 目录，包含 train.jsonl 和 val.jsonl

**Q: 如何修改数据？**
A: 直接编辑 `datasets/{角色ID}/train.jsonl` 文件

**Q: 删除角色会删除什么？**
A: 数据集、所有训练输出、配置文件条目（不可恢复）

**Q: 训练失败怎么办？**
A: 选择菜单 3) 系统状态检查 → 3) 全面环境诊断

