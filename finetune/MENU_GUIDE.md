## 1️⃣ 🎨 角色开发

**用途**：创建、查看、管理角色和数据集

```
==================================================
🎨 角色开发
==================================================
1) 🆕 创建新角色
2) 📋 查看所有角色
3) 🔍 查看角色详情
4) 🗑️  删除角色
5) 📊 数据集统计
```

### 1) 创建新角色
- 交互式收集角色信息
- 自动生成数据集模板
- 支持 AI 辅助生成初始数据
- 自动更新配置文件

**使用场景**：
- 想创建一个新角色
- 从零开始设计角色定位

**示例流程**：
```
输入角色ID → 输入基本信息 → 选择生成方式 → 完成
```

### 2) 查看所有角色
- 列出所有已创建的角色
- 显示名字和描述

**使用场景**：
- 想知道有哪些角色
- 快速浏览角色列表

### 3) 查看角色详情
- 基本信息（ID、名字、描述）
- 数据集状态（训练集/验证集数量）
- 训练输出（已有的模型文件）
- 训练参数配置

**使用场景**：
- 检查数据集是否充足
- 查看训练历史
- 确认参数配置

### 4) 删除角色
- 一键删除所有相关文件
- 包括：数据集、训练输出、配置
- 需要确认，防止误删

**使用场景**：
- 测试角色不满意，想重新创建
- 清理不需要的角色
- 释放磁盘空间

### 5) 数据集统计
- 查看所有角色的数据量
- 分析数据分布
- 发现数据不足的角色

**使用场景**：
- 评估哪些角色需要补充数据
- 查看数据集健康状况

## 2️⃣ 🚀 模型训练

**用途**：训练角色模型

```
==================================================
🚀 模型训练
==================================================
1) 🎯 选择角色开始训练
2) 📋 查看训练配置
3) 📊 扫描数据集状态
4) 💾 检查模型缓存
```

### 1) 选择角色开始训练
- 交互式选择角色
- 自动检查环境和数据
- 显示训练预估时间
- 开始训练流程

**使用场景**：
- 数据准备好了，开始训练
- 继续未完成的训练

**训练流程**：
```
选择角色 → 检查环境 → 确认配置 → 开始训练 → 完成
```

### 2) 查看训练配置
- 列出所有角色的配置
- 显示训练参数
- 查看数据文件路径

**使用场景**：
- 确认参数设置是否正确
- 对比不同角色的配置

### 3) 扫描数据集状态
- 检查所有数据文件是否存在
- 统计数据量
- 发现问题（缺失、格式错误）

**使用场景**：
- 训练前检查数据准备情况
- 排查数据相关问题

### 4) 检查模型缓存
- 查看下载的基础模型
- 显示缓存位置和大小
- 确认模型是否需要重新下载

**使用场景**：
- 首次训练前检查基础模型
- 排查模型下载问题

## 3️⃣ 📦 模型部署

**用途**：将训练好的模型导入 Ollama 并测试

```
==================================================
📦 模型部署
==================================================
1) 📥 导入模型到Ollama
2) 📋 查看Ollama模型列表
3) 🗑️  删除Ollama模型
4) 🧪 测试模型效果
```

### 1) 导入模型到Ollama
- 选择训练好的模型
- 自动转换为 GGUF 格式
- 导入到 Ollama
- 设置推理参数

**使用场景**：
- 训练完成后导入使用
- 更新已有模型

**导入流程**：
```
选择模型 → 转换GGUF → 导入Ollama → 完成
```

### 2) 查看Ollama模型列表
- 显示所有已导入的模型
- 包括模型大小和更新时间

**使用场景**：
- 查看有哪些可用模型
- 确认导入是否成功

### 3) 删除Ollama模型
- 从 Ollama 中删除模型
- 释放磁盘空间

**使用场景**：
- 删除不需要的测试模型
- 清理旧版本模型

### 4) 测试模型效果
- 与模型进行对话测试
- 验证训练效果
- 发现问题

**使用场景**：
- 导入后测试是否正常
- 评估训练效果
- 对比不同版本

## 💡 完整工作流示例

### 从零开始创建角色并部署

```
1. 创建角色
   ./train --menu → 1) 角色开发 → 1) 创建新角色
   输入信息，生成数据集

2. 补充数据
   编辑 datasets/{角色ID}/train.jsonl
   目标：至少 200 条，推荐 1000+

3. 验证数据
   ./train --menu → 4) 系统工具 → 2) 验证数据集格式
   确保格式正确

4. 开始训练
   ./train --menu → 2) 模型训练 → 1) 选择角色开始训练
   等待训练完成

5. 导入模型
   ./train --menu → 3) 模型部署 → 1) 导入模型到Ollama
   转换并导入

6. 测试效果
   ./train --menu → 3) 模型部署 → 4) 测试模型效果
   验证训练效果

7. 不满意？重新训练
   - 调整参数：编辑 character_configs.yaml
   - 补充数据：编辑 train.jsonl
   - 重新开始：./train --menu → 2) 模型训练
```
